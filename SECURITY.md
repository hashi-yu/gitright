# Security Policy

## Reporting a vulnerability

[GitHub private vulnerability
reporting](https://github.com/hashi-yu/gitright/security/advisories/new) is the
only formal channel for reporting a GitRight vulnerability.

Private vulnerability reporting requires a GitHub account. GitRight publishes
no security-reporting email and offers no email fallback. Do not disclose a
suspected vulnerability in a public Issue, pull request, Discussion, or conduct
report.

Include the affected GitRight version, impact, reproduction steps, and any
suggested mitigation. Remove credentials, private repository content, personal
paths, and unrelated host data before submitting evidence.

Reports are handled on a best-effort basis. The beta does not promise an
acknowledgement or resolution deadline.

## Security boundary

GitRight is a read-only local history viewer. After prerequisites and plugin
installation are complete, its runtime makes no network requests. Security
reports that question either boundary are in scope.
