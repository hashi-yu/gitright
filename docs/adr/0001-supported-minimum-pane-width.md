# Set the supported minimum pane width to 380 CSS pixels

GitRight guarantees its complete experience at widget viewports of 380 CSS pixels or wider, replacing the earlier 320-pixel target. This is approximately 10 cm in CSS absolute-unit terms, but CSS pixels are the testable requirement because GitRight cannot guarantee physical display size or enforce the Codex pane width; the wider boundary gives the history graph more room at the cost of supporting fewer ultra-narrow layouts.
